# Project Navigation Guide

Welcome to the research workspace for the RoSEF26-27 project. This
document provides a starting point for exploring the documentation,
code, and results.

## 1. Documentation and Personal Section

The `docs` folder contains the project documents, including
`project-overview.md`, `ethics.md`, and the other documentation
materials.

Both the project's explanations and the personal story behind the
work can be followed here.

## 2. Python Code Integration

The Python code contains components of high complexity.
Nevertheless, the project structure makes it possible to identify the
main stages of the algorithms and the links between them.

The folders dedicated to computer science contain components for data
generation, CNN analysis, HNP formulation and solving, and experiment
execution.

## 3. Project Mathematics

The `matematica` folder contains the project's theoretical and
experimental components.

`matematica/README.md` contains the basic theory, while the
subfolders dedicated to experiments contain the graphs and analyses
associated with the mathematical problems studied.

## 4. Notebooks

The `notebooks` folder presents the experimental steps in a format
that is easier to follow.

These files connect generated data, model training and evaluation,
and the final stages of the experiment. They are also useful for a
reader who wants to follow the experiment without reviewing every
code component separately.

## 5. Results

The `results` folder contains output data and experimental results
in a format that is easier to consult.

Here, the values obtained in the experiments and the pipeline's final
results can be followed.

The project links these components into a single workflow, from the
mathematical portion and data generation to computer analysis and
result verification.
